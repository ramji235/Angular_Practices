Angular Pipes

Pipes are used to transform data before displaying it in the HTML template.

1. Uppercase Pipe

Original: hello angular

Output: {{ 'hello angular' | uppercase }}

{{ 'hello angular' | uppercase }}

2. Lowercase Pipe

Original: HELLO ANGULAR

Output: {{ 'HELLO ANGULAR' | lowercase }}

{{ 'HELLO ANGULAR' | lowercase }}

3. Titlecase Pipe

Output: {{ 'angular pipes tutorial' | titlecase }}

{{ 'angular pipes tutorial' | titlecase }}

4. Date Pipe

Current Date: {{ today | date }}

Formatted Date: {{ today | date:'dd/MM/yyyy' }}

{{ today | date:'dd/MM/yyyy' }}

5. Currency Pipe

Price: {{ price | currency:'INR' }}

{{ price | currency:'INR' }}

6. Number Pipe

Number: {{ numberValue | number:'1.2-2' }}

{{ numberValue | number:'1.2-2' }}

7. Percent Pipe

Percentage: {{ percentage | percent }}

{{ percentage | percent }}
